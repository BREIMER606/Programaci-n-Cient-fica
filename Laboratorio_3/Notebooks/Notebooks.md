# Notebooks

This directory contains Jupyter notebooks associated with the course and with the final version of the project. The notebooks are **documentation and explanation tools**, not the main execution path of the code (the full pipeline is run through `Main.py` in the project root).

## Structure

- `assignments/`
  - `Lab1_Pct.ipynb`
  - `Lab2_Pct.ipynb`
- `reporting/`
  - `reporting.ipynb`

### `assignments/` – prior course work

The notebooks in the `assignments/` subfolder correspond to earlier laboratory exercises from the same Scientific Programming course. They include exploratory code, partial analyses and alternative implementations that were used as a foundation for this repository.

These notebooks are kept here as:

- a **reference** for design decisions and intermediate experiments,
- an **auxiliary execution path** if a different, more exploratory workflow is needed,
- material that documents the evolution from ad‑hoc scripts to the final structured project.

They are not directly invoked by `Main.py`, but they remain valuable for understanding how the current approach was derived.

### `reporting/` – Big‑O and pipeline documentation

The `reporting/reporting.ipynb` notebook is designed specifically for this project:

- It is **not intended to be executed end‑to‑end**.  
  Instead, it reproduces the main functions from `Src/preprocessing`, `Src/visualization` and `Src/analysis` in English and annotates each one with its **Big‑O computational complexity**.
- The notebook also embeds the figures and tables previously generated by running `Main.py` (filter comparisons, boxplots, violin plots, heatmaps, integration plots, segment summaries, feature tables, confusion matrix, and classification report).
- The goal is to present, in a single document:
  - the **structure** of the pipeline,
  - the **complexity analysis** of each algorithm,
  - and an **organized view of the final results**, without re‑running the full analysis.

In summary, the `reporting` notebook acts as a readable technical report built on top of the reusable code in `Src/`, while the `assignments` notebooks provide historical context and supplementary examples from earlier stages of the course.
