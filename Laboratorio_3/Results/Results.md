# Results

This directory stores all outputs generated by the project pipeline.  
Files are created automatically when running `Main.py`, and are not meant to be edited by hand.

## Structure

- `figures/`
  - PNG images with plots and visualizations:
    - `heatmap_variables.png` – Correlation heatmap over the selected variables.
    - `boxplot_variables.png` – Boxplot of the main physical variables.
    - `violinplot_variables.png` – Violin plots showing the distribution of physical variables.
    - `integracion_acc.png` – Acceleration vs. integrated velocity for each accelerometer axis.
    - `rf_confusion.png` – Confusion matrix of the Random Forest classifier.

- `tables/`
  - PNG images containing tables rendered from pandas DataFrames:
    - `tabla_crudos.png` – Summary of total values and missing data per sensor segment (raw dataset).
    - `tabla_procesados.png` – Same summary after preprocessing (processed dataset).
    - `tabla_features.png` – Time/frequency-domain features extracted from accelerometer signals.
    - `tabla_clases.png` – Class distribution for the global motion states (repose / transition / motion).
    - `rf_reporte.png` – Classification report (precision, recall, F1-score, support) for the Random Forest.

## How results are generated

All results are produced by running the main script from the project root:

The script orchestrates three stages:

1. **Preprocessing** – loads the raw CSV and writes a cleaned version to `data/processed/`.
2. **Visualization** – creates exploratory plots and saves them under `results/figures/`.
3. **Analysis** – integrates accelerations, builds summary tables, defines motion classes, extracts features, and trains a Random Forest classifier, saving all tables under `results/tables/` and the confusion matrix under `results/figures/`.

You can safely delete the contents of `results/` if needed; they will be recreated the next time the pipeline is executed.
